# A1–A7 Assumption Scorecard

Update after each wave of ~5 interviews per segment. Stop interviewing when answers stop surprising you (saturation).

**States:** Not started · Mixed · Validated · Invalidated — record honestly.

| # | Assumption | Evidence required to call it validated | Status | Wave 1 notes | Wave 2 notes |
|---|------------|----------------------------------------|--------|--------------|--------------|
| **A1** | Recurring emotional strain | Most end users describe a *recurring* pattern with a specific recent instance | Not started | | |
| **A2** ⚠️ | Language/culture is the barrier | Multiple concrete examples of something they could not express in a second language | Not started | | |
| **A3** | Costly and already acted on | Evidence of prior searching, spending or effort — not just stated intent | Not started | | |
| **A4** ⚠️ | Quantified employer pain | At least a few employers give a *number* and a *named owner* | Not started | | |
| **A5** | Budget, buyer, process | A traceable past purchase, a named signer, and a budget cycle | Not started | | |
| **A6** | Facilitators recruitable | 5–8 viable candidates in Wave 1 languages at workable rates | Not started | | |
| **A7** | The middle space is real | Both members and facilitators recognise pre-clinical support as legitimate | Not started | | |

⚠️ **A2 and A4 are the sharpest knives** — if either fails, the venture as designed does not work.

## Phase 1 exit gate

Proceed to Phase 2 only when all of these hold:

- [ ] A1–A3 validated with end users
- [ ] A4–A5 supported by at least a few employers with costed pain, budget owner, and pilot interest
- [ ] At least one signed letter of intent from a pilot employer
- [ ] A6 plausible — 5–10 vetted facilitators ready in Wave 1 languages
