Foundations · Typography

Type & the multilingual decision

Deliberate constraint: the product lives or dies on rendering Arabic, Chinese, Cyrillic and more beautifully — so the UI face is Noto-first (Inter for Latin, falling back to Noto Sans / Noto Kufi Arabic / Noto Sans SC for full script coverage). Fraunces, a humanist serif, carries display headings with warmth. This is a brand constraint, not an afterthought.

For developers

Copy the tokens

Drop this :root block in as the single source of truth. Every colour, type, space, and radius decision references a token — no hard-coded hex in components.

/* tamia4life.tokens.css */
:root{
  /* color · primary */
  --t4l-teal:#0f6d68; --t4l-teal-deep:#0a4f4b; --t4l-teal-bright:#0d9488;
  /* color · accent + warmth */
  --t4l-amber:#e7a13a; --t4l-amber-deep:#cf871e; --t4l-clay:#c56a52;
  /* color · growth ramp (seed→canopy) */
  --t4l-grow-0:#0a4f4b; --t4l-grow-1:#0f6d68; --t4l-grow-2:#2f8a6e;
  --t4l-grow-3:#7ba33f; --t4l-grow-4:#cf871e;
  /* color · neutrals */
  --t4l-ink:#1f2e2c; --t4l-ink-soft:#4a5b58; --t4l-paper:#f3f0ea; --t4l-card:#ffffff;
  /* type — Noto-first for full script coverage */
  --t4l-font-display:"Fraunces",Georgia,serif;
  --t4l-font-ui:"Inter","Noto Sans","Noto Kufi Arabic","Noto Sans SC",system-ui,sans-serif;
  /* space (4px base) · radius */
  --t4l-space-4:16px; --t4l-space-5:24px;
  --t4l-radius-md:12px; --t4l-radius-pill:999px;
}
