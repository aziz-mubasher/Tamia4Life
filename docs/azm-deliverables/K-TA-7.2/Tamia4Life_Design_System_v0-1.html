Changelog

Driven by S TA 2.B — Community and Language Strategy. Only typography changed; every colour, space, radius and elevation token from v0 carries over untouched, so nothing built on v0 breaks.

RemovedNoto Sans SC dropped from --t4l-font-ui. The Chinese-speaking community is excluded from the target set by strategic decision.
AddedNoto Sans Bengali — serves Bangladeshi and West Bengali Indian members.
AddedNoto Sans Devanagari — Hindi (and Marathi/Nepali if the set widens).
AddedNoto Sans Gurmukhi — Punjabi for Indian Sikh members. Note: Pakistani Punjabi uses Shahmukhi, which renders through the Urdu face, not this one.
New ruleUrdu is a separate rendering target. New tokens --t4l-font-urdu, --t4l-lineheight-urdu and --t4l-size-adjust-urdu, applied via [lang="ur"]. Urdu is deliberately not in the main UI stack.

The one that bites

Urdu is not Arabic

Both are right-to-left, so it's tempting to treat Urdu as an Arabic variant. It isn't. Nastaliq slopes steeply down the line and needs far more vertical room — an Arabic-tuned line-height clips descenders. This is the single most likely rendering bug in the multilingual build, so the rule is a token, not a convention.

Same string, same font — only line-height differs

✗ Arabic metrics · line-height 1.5

آئیے آپ کی زبان میں شروع کرتے ہیں

Descenders collide and clip. This is what inheriting the Arabic rule produces.

✓ Nastaliq metrics · line-height 2.4

آئیے آپ کی زبان میں شروع کرتے ہیں

Legible and correctly spaced. Applied automatically via [lang="ur"].

Rule for the team: never branch on dir="rtl" to pick a font. Branch on lang. RTL tells you the direction; it does not tell you the script.

Onboarding · step 1

For developers

The corrected typography tokens

Replace the v0 typography block with this. Everything else in :root stays as it was.

/* tamia4life.tokens.css — v0.1 typography */
:root{
  --t4l-font-display:"Fraunces",Georgia,serif;

  /* UI stack — ten-community coverage. NOTE: no Noto Sans SC. */
  --t4l-font-ui:"Inter","Noto Sans","Noto Kufi Arabic",
                 "Noto Sans Bengali","Noto Sans Devanagari",
                 "Noto Sans Gurmukhi",system-ui,sans-serif;

  /* Urdu — separate target. Do NOT fold into --t4l-font-ui. */
  --t4l-font-urdu:"Noto Nastaliq Urdu",serif;
  --t4l-lineheight-urdu:2.4;
  --t4l-size-adjust-urdu:1.05;
}

/* Branch on lang, never on dir. */
[lang="ur"]{
  font-family:var(--t4l-font-urdu);
  line-height:var(--t4l-lineheight-urdu);
  font-size:calc(1em * var(--t4l-size-adjust-urdu));
}
Source: S TA 2.B — Community and Language Strategy.
